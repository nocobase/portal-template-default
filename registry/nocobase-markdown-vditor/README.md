# NocoBase Markdown Vditor

Controlled Vditor editor and safe read-only Markdown renderer for fields provided by `@nocobase/plugin-field-markdown-vditor`. Supports IR, split-view, and WYSIWYG modes, standard toolbar actions, fullscreen, preview, sanitization, and optional file upload through the plugin's `vditor:check` storage contract. See `/dev/markdown-vditor`.
